# 228: interpretations fixed before native True observation

The new test asks whether two previously identified nonlinear receiving writes can forecast native gate/up alignment when embedded in a declared False-only transport rule. It does not repeat the earlier local deletion result.

The prior evidence gives two reasons for caution. Removing native MLP22/23 writes mattered, but a small projection of those writes did not reconstruct the native behavior. The latest MLP24 product term explained much of a conditional margin gap while failing its vector criterion. Neither result implies that finite evaluation at an inaccurate predicted input will supply the missing native direction.

The fixed finite arm therefore uses MLP22/23 at its own predicted incoming states. The linear arm and a control with the same candidate correction norm but randomized orientation are forecast from the same observed False computation. The random correction's norm is matched at its own current incoming state; after the first selected update it need not equal the finite arm's edit norm. All arms evaluate the known source and final tail finitely. This has a substantial declared computation budget and is not a compact circuit model.

Before observing any fresh native True receiving trajectory, the interpretations are:

- Accurate signed parent vectors, meeting the frozen absolute/relative bounds and beating both controls, would support these selected nonlinear writes as a useful generator of the required alignment under this transport rule. It would not explain the source encoder or identify learned features.
- Better angles with an incorrect magnitude would remain a failed quantitative account. Better margins with incorrect vectors would also remain a failure.
- Accurate target parents with an inaccurate final native response would require a further account of the carried residual, other receiving positions and the remaining nonlinear response. A local-parent success cannot stand in for the stronger final target.
- Failure of the finite arm would reject the claim that this selected update is sufficient within the specified approximation. It would not establish that the native writes are irrelevant, nor falsify every possible alignment explanation.

The observed True trajectories may subsequently diagnose where errors were already present. That diagnostic cannot be fed back into these forecasts or relabeled a fresh prediction. No output-driven site sweep, native-state reset or rescaling is part of this experiment.

The primary question remains generation of the displacement, rather than merely reducing a scalar error. The complete criteria, numerical scope and information budget are in the [protocol](../experiments/228-false-only-alignment.md).
