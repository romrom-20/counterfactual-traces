# The query correction has an exact two-scalar geometry

This retrospective diagnostic explains an algebraic part of the successful
254 correction. It makes no model calls, uses all 32 already observed contexts
and all 28 layers, and does not predict a new native final response.

For a False residual x and displacement d, define
`s²=mean(x²)+eps`, `a=mean(x*d)/s²`, `b=mean(d²)/s²`, and
`r=(1+2*a+b)^(-1/2)`. The exact smooth RMSNorm remainder beyond its False
tangent is

`E(d)=gamma/s * [(r-1+a)*x+(r-1)*d]`.

It lies in the span of gamma*x and gamma*d. This is a normalization identity,
not evidence for two learned mechanisms or semantic features. The particular
displacement d still has to be generated by the rest of the network.

The second-order term is
`gamma/s * [(1.5*a²-.5*b)*x-a*d]`.
The third-order addition is
`gamma/s * [(1.5*a*b-2.5*a³)*x+(1.5*a²-.5*b)*d]`.

Across eligible native case/layer whole-receiving remainders, the quadratic
approximation has **25.49% median relative error**. Adding the cubic term
reduces that to **5.37%**. Eligibility requires remainder norm >=1e-8; every
outcome including zero cases is retained. At these native inputs, the median
of each layer's maximum receiving-row |a| is .0542, and the corresponding
maximum b is .0759. These describe this dataset, not a stability theorem.

The exact remainder evaluated at D0's approximate inputs has **4.46% median
error against the native-input remainder**. Evaluating it at P1's inputs
reduces that to **.195%**, and P2's inputs to **.0060%**. These are local
case/layer medians, not final residual errors or a measured contraction factor.
They clarify how a coarse trajectory can already give a useful estimate of
the term needed by a subsequent trajectory.

All **14,384 declared checks pass**, maximum discrepancy **4.213e-8**: exact
two-scalar identity, independent generic polynomial-jet coefficients and
fixed-witness second centered differences. The checks concern smooth CPU64
RMSNorm algebra, not old Float32/whole-block derivative disputes. Input array
hashes are checked against the qualified 254 record. No primitive intervention
or new behavioral measurement occurs here.

The resulting prospective question is specific: can cubic local terms at a
forecast's own current inputs replace the preceding complete seed/correction
trajectories? Experiment 256 freezes that rule and criteria before running new
literals. Even success would retain finite source, K/V and MLP computation.
