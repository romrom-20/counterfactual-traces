## Hypothesis and arms

Use one ordinary False computation, one exact edited block 1 and one source-only
attention-2 call per pair, as in 231. These are declared counterfactual component
computations, not an explanation of block 1 or an efficiency claim. The source-
only state S=x+s is already available. It changes attention's keys, values and
probability background even though the receiving inputs remain False.

Let YF be the finite/affine graph anchored at original False, and YS the same
graph anchored at S. The graph input is receiver-only native carry for YF and
the full known first-block state for YS; both directions are zero on their
respective prefix/source. Graph bits remain N,K,S,V.

```
FNV = public A(S) + JF d + (YF1001 - YF0000)    # previous rule
SL  = public A(S) + JS d                      # source-conditioned linear
SNV = public A(S) + (YS1001 - YS_false)        # same operators, new context
R   = FNV + Gaussian_norm_match(SNV - FNV).
```

Use public A(S) plus promoted increments to avoid an artificial anchor rounding
shift. Independent derivative caches for F and S are mandatory: the local
direction hash alone does not encode its anchor. Norm matching is over the
whole receiving vector, with a fixed SHA seed; no fitting or target rescaling.
