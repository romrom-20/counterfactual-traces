## Competing explanations

The late source-value clamps in250b establish a conditional necessity result.
They do not establish whether schema dependence resides in different source
signals or different receiving computations. Test the strong portable-signal
hypothesis by replacing only the source's value **change**, using a donor with
the other schema. Each recipient retains its own False value baseline, native
source keys, evolving queries, other values, normalization, MLPs and finite head.

## Arms and frozen primary

Let d be recipient generated sourceTrue V minus sourceFalse V, and e the matched
donor difference. Differences are CPU64 subtractions of public Float32 values.
At every layer install recipientVFalse plus:

- U: d (self substitution; must exactly replay native T).
- X: e (raw other-schema donor; the primary).
- D: donor direction, recipient norm, separately within each of the two KV heads.
- A: recipient direction, donor norm, separately within each KV head.
- Z: zero (remove the native source value change).
- R: deterministic random direction with each recipient KV-head norm.
- FZ: False input and unchanged False values; must exactly replay False.
- T: unmodified native True, measured after the interventions.

Native source-only computation is allowed before T; full True receiver targets
were already observed269/272. This order is not a fresh or globally blind seal.
No arms replace keys. Query, remaining K/V, source generation and all MLPs remain
finite; these are artificial causal interventions, not learned feature labels.

Primary target is the native source-value effect U-Z at the final state. Compare
X-Z against it, for all receiving rows and separately the verdict: target norm

The norm/direction arms are prespecified explanatory controls, not alternate

At each native T attention input, additionally save the receiving vectors for

These are same-input local effects. The full intervention arms test their
