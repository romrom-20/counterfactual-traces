## Question and competing explanations

273 showed that exchanging the post-normalization source dV between whole schema
backgrounds fails its value-effect criterion5/32; matching V magnitudes gives4/32.
It does not show that the underlying source residual displacement itself must
have a different learned meaning. RMS normalization can turn one displacement
into different output directions around different False states.

At each source input let x be the observed False residual and h the generated
True-minus-False residual. Define the finite emission map

`M(x,h) = Vproj(RMS(x+h)) - Vproj(RMS(x))`.

The paired other-schema donor supplies y,k. 273 exchanged M(y,k). Test whether
reanchoring k at x accounts for the missing native signal. P uses only recipient
False state, donor-calibrated step and pinned weights for its emitted values.
The recipient's source K and actual source computation remain native in all True
continuations, so this is NOT a cheap full False-only prediction rule.

Pairs match passage family, assignment, target and order. Full prompt wording,
length and absolute positions differ: no pure field-meaning inference is allowed.

## Prespecified emission fields

- U=M(x,h): self/native control, must replay273 exactly.
- P=M(x,k): primary paired reanchoring.
- C=M(x,h_ref): a single fixed old reference's complete residual-step trajectory;
  the reference is the first case in public cases269 order, selected before new
  computation. This checks portability beyond a passage-matched donor.
- D=M(y,h): complementary background exchange. Uses recipient True displacement
  from old data; oracle geometric control, not a prospective input.
- E=M(x,h_embed): repeat the known True-minus-False embedding difference at all
  layers, testing whether evolution of the source displacement matters here.
- R=M(x,k_random): deterministic per-case/layer random hidden-space direction,
  norm-matched to k BEFORE normalization. Not an on-manifold/output-norm control.
- X=M(y,k): exact archived273 raw donor-V field.
- J=P+D-X: additive center/displacement account, using the same four finite
  normalization corners. Its omitted mixed field is I=U-J. J is an oracle
  decomposition control, not a prospective predictor or the primary.
- Z=0: remove the source value change.
- FZ: False input and unchanged False source values, zero-edit control.
- F/T: ordinary False/True native replay controls, actual finite readout.

Initial source inputs are pinned False/True embeddings. For layer i>1, x is the
previous False source residual; h is the previous generated True source residual
minus that False residual. The donor source trajectories were separately
qualified in273. They are old calibration information, not free fresh targets.

All M maps use actual full-sequence-shape Float32 public RMS and V projection.
Differences and corner sums use CPU64 public outputs, with one Float32 cast when
installing recipientVFalse+field at the value primitive. Query rows strictly
after the source receive the change; prefix/source outputs stay native.
Receivers, queries, other K/V, all MLPs and final RMS/full vocabulary head evolve
finitely. Save complete tail trajectories, actual scores and every map operand.
