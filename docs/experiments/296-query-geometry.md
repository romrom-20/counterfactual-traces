## Competing questions

252 found a large quantitative role for adaptive receiving queries without
separating rescaling of a fixed preference from changing the preferred content.
For fixed keys, multiplying one query by a positive scalar rescales its logits
without changing their rank (an inverse-temperature change). Changing its
orientation can change which keys are preferred. Keys remain live here, so a
magnitude-only arm does NOT freeze attention rankings globally.

At every head and receiving query strictly after the edited Boolean, let qF
be the post-RoPE query from the ordinary False observation and q the CURRENT
query from that candidate's OWN evolving state. Source/prefix queries stay native.
All keys, values, softmax, attention output projections, norms, MLPs, residuals
and final full-vocabulary head remain finite and adaptive.

- A (PRIMARY magnitude-only):qA=qF*||q||/||qF||.
- D (direction-only):qD=q*||qF||/||q||.
- B (neither):qB=qF.
- R (angular control):retain q's component along qF, replace its orthogonal
  component by a seeded random direction orthogonal to qF at the same norm.
  Thus R preserves current query norm and angle to qF at its OWN input, while
  changing the orientation of the turn. It is not an on-manifold control.
- T:ordinary True native reference, observed only AFTER all forecasts are sealed.
- O:True with current queries and recomputed attention; numerical calibration.

A/D/B/R start from the known True token edit, one observed False query trace and
weights. No True hidden states, scores or gradients enter forecasts. Each runs
the full finite model and computes the current query before its replacement;
no speedup or compact prediction claim. Query geometry alone cannot identify
semantic features or a uniquely necessary learned circuit.

Maps use CPUFloat64 norms/products then cast to originalFloat32. qF and q norms
must exceed1e-12, except an exact equal-query bypass returning that query unchanged.
Random directions are seeded by case/layer and projected off each False query;
zero tangent norms are rejected. No seed, head, rank or layer search.
